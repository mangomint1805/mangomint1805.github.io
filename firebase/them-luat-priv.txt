THÊM LUẬT FIRESTORE CHO "ĐIỂM CỦA MÌNH" (priv/)
===============================================
Chỉ THÊM đoạn dưới vào luật đang chạy. KHÔNG xoá gì, KHÔNG Publish đè bằng file firestore.rules trong repo.

Các bước:
1. Mở https://console.firebase.google.com → project minto-english → Firestore Database → tab Rules.
2. Tìm dòng   match /config/{doc} {   (đoạn "Mã giáo viên: chỉ thầy đọc/ghi").
3. Dán đoạn bên dưới NGAY TRÊN dòng đó (vẫn nằm trong   match /databases/{database}/documents { ... }).
4. Nếu luật đang chạy KHÔNG có hàm me(uid) và gv(): thay  me(uid)  bằng
      request.auth != null && request.auth.uid == uid
   và thay  gv()  bằng đúng điều kiện đang dùng ở dòng  allow read, write  của  match /config/{doc}
   (điều kiện có email của thầy — email chỉ nằm trong Console, không đưa lên GitHub).
5. Bấm Publish. Mở gv.html → tab 📝 Bài test → chọn lớp → bấm "📤 Cập nhật điểm cho học viên".
   (Dòng cảnh báo vàng "Cần thêm luật Firestore" biến mất là xong.)
6. Kiểm tra (tuỳ chọn): tab Rules → Rules Playground → get /priv/abc với Authenticated, uid khác "abc"
   → phải ra Denied; uid = "abc" → Allowed.

----- ĐOẠN CẦN DÁN (từ dòng dưới đến hết) -----
    // Điểm của mình (điểm cộng + điểm Minitest/Mock test): chỉ chính chủ và thầy đọc, chỉ thầy ghi.
    match /priv/{uid} {
      allow read: if me(uid) || gv();
      allow write: if gv();
    }
----- HẾT -----

Ghi chú:
- Sổ điểm cộng gốc của thầy nằm ở config/pts (đã chỉ thầy đọc/ghi theo luật config/ hiện có, không cần thêm gì).
- Học viên KHÔNG đọc được config/erp, config/roster, config/subs (khoá đọc bài nộp): web của học viên chỉ đọc priv/{uid của chính mình}.
